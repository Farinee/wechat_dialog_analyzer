Original db.py SHA256: 1B8958A0E9A3F8D6C2F8FE89ACD72C14BB542C3C16635C31B52E05C0F19B247B

Adaptations:
- Only the database reader is included. The original package initializer,
  sending functions and UI/process-writing automation are not included.
- A minimal strict logger reports partial/stale snapshot warnings as errors.
- A subclass keeps database keys encrypted with Windows DPAPI in the app's data
  directory instead of upstream plaintext key caches.
- Decrypted snapshots are placed in temporary app-owned cache directories and
  removed after each operation.
- Group selection, indexing, DeepSeek retrieval and the desktop interface are
  implemented separately by WeChat Memory.

This is a Python source project. It runs on the user's existing Python/Tcl/Tk
installation and requires cryptography (with cffi), zstandard, Pillow and
imageio-ffmpeg (including its FFmpeg binary). No Python
runtime or PyInstaller bootloader is distributed with this source project.
